# ConviApp
ConviApp is a comprehensive cross-platform application designed to simplify co-living by managing shared expenses, automating balance settlements, and organizing household chores. The system features a client built with .NET MAUI, a REST API powered by Python (FastAPI) and PostgreSQL, and a background integration with Odoo for monthly accounting.

This repository contains the final Intermodular Project for the Higher Technical Degree in Multiplatform Application Development (DAM).
